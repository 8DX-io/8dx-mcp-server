# Security Policy

## Reporting a Vulnerability

Please report security issues privately before opening a public issue.

Use GitHub Security Advisories for this repository when available. If advisories are not available,
contact the maintainers through the official 8DX or Planet 9 communication channels listed in the
project README.

## Scope

This MCP server is a stateless wrapper around the 8DX REST API. It does not store private keys,
seed phrases, wallet sessions, API credentials, or signed payloads.
